# Host baselines

Reviewed full-level, steady measurements go here as `<host>.json`, generated by sub0perf.
There is deliberately no imported Sub0Math baseline: its workloads, host and build differ.
A `new` row means unbaselined, not a performance pass. See docs/PERFORMANCE.md for recording,
explicit acceptance, and the iteration evidence contract. Generated raw samples stay in `out/`;
commit only reviewed host baselines with the corresponding issue/PR rationale.
