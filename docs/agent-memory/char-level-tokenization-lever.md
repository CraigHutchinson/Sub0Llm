**WHY BPE-512 fails — refined mechanism (2026-06-19, inspected the actual vocab).** It is NOT bad/low-frequency token choice: the BPE-512 founded vocab (514 tokens) DOES contain the high-frequency whole words as single tokens (the/and/thou/thee/thy/you/that/with/king/lord/love/heart/sir all present). Composition: 138×1-char, 181×2-char, 127×3-char, 53×4-char, 11×5-char; 235 mid-word continuation fragments (AL/EN/ER/ON/ST/con/ick/ed/ers…). The real cause is DIFFUSION-SPECIFIC: (1) ~60% of the vocab is multi-char fragments (only top words earn whole tokens; the rest must be ASSEMBLED), (2) masked diffusion denoises positions from their MARGINALS with no left→right constraint, so it commits `con` then `ick` then `ers` — each locally probable, the whole a NON-word (no spelling coordination), (3) error granularity: a wrong CHAR = 1-char blemish in a real word (`nighthe`); a wrong FRAGMENT = a whole visible non-word chunk (`WIACHER`). ⇒ char-level's graceful degradation is a DIFFUSION advantage, not universal — an AR model leans on left-context to keep the next fragment word-consistent. TESTABLE PREDICTION: AR-GPT on BPE-512 should produce far LESS salad than diffusion on BPE-512 (motivates the owed AR baseline).
