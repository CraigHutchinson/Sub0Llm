**RE-CONFIRMED AT CHAR-LEVEL 2026-06-19 (recall probe on /d/tmp/ch29_char step6300, V=101 T=128, 200 windows).** The LOCAL-INTERPOLATOR finding is NOT a BPE artifact — it holds at char level: scattered recall HIGH (single 68%, scatter-25% 61.7%, scatter-50% 44.5%) but contiguous recall PINNED ~16% and FLAT across context given (continuation give-75% 16.5%, give-25% 16.1%, 2-anchors/98%-masked 16.0%). Smoking guns: (a) identical 50% mask → scattered 44.5% vs contiguous-middle 17.1% = 2.6× gap (only difference = visible immediate neighbors); (b) giving MORE context does NOT raise contiguous recall ⇒ long-range context is IGNORED. ⇒ ANSWER to "is our bidirectional/parallel denoiser working?": YES bidirectionally but ONLY short-range (local interpolation); it does NOT model long-range structure. Free generation = filling a fully-masked canvas = the 98%-masked regime = ~16% local-statistics floor ⇒ loose grammar. ROOT CAUSE = train/use mismatch: scattered masking only ever rewards local interpolation. This is the PRIMARY MOTIVATION for the tree predictor (parent-scaffold supplies the long-range coordination the flat denoiser lacks; [[ch29-char-level-run-results]], ch32_tree_predictor design doc). NOTE the data-ceiling framing below was BPE-confounded (coherence ceiling was tokenization, [[char-level-tokenization-lever]]) — but the LOCAL-INTERPOLATOR / long-range-failure observation itself is REAL and now char-confirmed. CHEAPER pre-tree test DONE 2026-06-19 — §13.5 RE-CONFIRMED UN-CONFOUNDED at char level. Trained char-level `--contiguous` (matched to scattered baseline, /d/tmp/ch29_char_contig); NELBO plateaued fast at ~3.18 (scattered hit 2.10 same step). Recall probe of the contiguous-trained model: EVERYTHING collapsed to the ~15.7% UNIGRAM FLOOR regardless of scenario (single 18%, scatter-50% 15.5%, contiguous ~15.7%, 2-anchors 15.7%) — i.e. training ON contiguous spans did NOT raise contiguous recall AND destroyed scattered recall (44-68%→15.5%). Mechanism: a contiguous span's INTERIOR positions have NO visible neighbors → single-pass parallel prediction falls back to the unigram prior; the model can't propagate distant info across a fully-masked span. ⇒ the ONE-STEP local-interpolator limit is NOT fixable by training objective / masking pattern (FLAT pass can't propagate across a fully-masked span). Objective-mismatch hypothesis FALSIFIED at BOTH BPE and char level.

**CORRECTION (§13.8c, 2026-06-19) — one-step ≠ generation; do NOT conclude "tree predictor required."** Generation uses ITERATIVE confidence decoding (commit confident tokens → they become visible neighbours → refine), so it BOOTSTRAPS the local interpolator (contiguous gap → scattered). tiny-diffusion's masking is ALSO scattered Bernoulli (per-token, mask_prob~U(0,1), plain masked-CE) — same family as ours — yet it generates coherent Shakespeare. ⇒ the differentiator is RECIPE (char + capacity 10.7M + context block256 + 10k steps), NOT masking or "flat architecture." Flat scattered diffusion DOES generate coherently with the right recipe (also DiffusionGemma-26B). So coherence is RECIPE-bound not architecture-bound; tree predictor is a possible improvement not a required fix → PARKED ([[tree-predictor-parked-research-diffusion-training]]). The one-step recall numbers above are still valid; only the "must be structural" interpretation was the overreach.

**UPDATE 2026-06-18 — the lever was TESTED and FAILS at this scale (TRAINING_DESIGN §13.5).** A/B: `--contiguous` 157K, identical arch/data/curriculum to the scattered small run. Result: continuation/infill recall UNCHANGED (continuation give-75% 4.1% vs scattered 4.3%; middle 5.3% vs 5.4% — still the ~4% floor), but everything else WORSE (single 50→22%, scatter-25% 37→18%, overall 16.7→9.8%, global NELBO 3.90→5.47 ≈ floor). The model could NOT learn span-filling even trained EXCLUSIVELY on it (NELBO pinned at floor from k≈9). ⇒ objective-mismatch hypothesis FALSIFIED at this scale: continuation/generation is a fundamental DATA/CAPACITY limit on long-range modeling (from 2M tokens/157K params only LOCAL interpolation is learnable). Confirms the data ceiling from a 2nd angle. Path to generation = more data+capacity, NOT a masking-pattern change. `--contiguous` flag + recall probe remain validated tools to re-test once data/capacity grow. The "fixable objective" framing below is SUPERSEDED (kept for context).

Major finding (2026-06-18), TRAINING_DESIGN §13.4. A structured single-forward recall probe (`sub0diff-recall-probe`, source `diffusion/tools/recall_probe/main.cpp`, debug-built) "breaks" real corpus windows in STRUCTURED ways vs the random/scattered masking of training. Across 3 checkpoints (6M@k36, 157K@k36, 157K converged), at the SAME 25% mask fraction: SCATTERED recall ≈ 60%/37% but CONTIGUOUS (continuation = give prefix, mask tail) ≈ 4–6%, middle-infill ≈ 5–10% — an **~8–9× collapse, universal across capacity and training**.

**Conclusions:** (1) every model is a LOCAL INTERPOLATOR — recovers a masked token from immediate VISIBLE neighbours, cannot fill a contiguous span. (2) Capacity scales INTERPOLATION not GENERATION (6M 60% vs 157K 37% scattered, but BOTH ~4–6% contiguous; more training barely moves contiguous). (3) This is WHY generation is word-salad: generation IS contiguous infilling = the ~5% regime. The headline "recall" (scattered = training dist) OVERSTATES capability ~9×.

**Root cause = train/use mismatch:** training masks RANDOM/SCATTERED positions → a masked token almost always has visible neighbours → the objective rewards local interpolation and never forces LONG-RANGE modeling.

**LEVER (actionable, largely orthogonal to the data ceiling):** add CONTIGUOUS/BLOCK masking to the training objective — suffix-masking (give prefix, mask tail), span masking, or semi-autoregressive schedule — so the model must model spans without local crutches. Plausibly the DOMINANT fixable cause of word-salad (even the high-interpolation 6M can't do contiguous), and it forces long-range modeling at FIXED data (vs the [[ch29-pause-state-and-data-matched-decision]] data-ceiling story, which it precedes). Relates to [[diffusion-loss-weighting-and-level-cadence]] (masking PATTERN, not just weighting) and the noise_schedule (`diffusion/include/sub0diff/nn/noise_schedule.hpp` already has whole-word masking; add block/suffix). Validate with the recall probe (continuation/middle) + Ch30 coherence. Run a fresh A/B in the [[ch31-diffusion-optimization-sandbox-plan]] sandbox; do not retrofit the founded/small runs.
