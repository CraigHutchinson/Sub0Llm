The full follow-up work plan lives in the repo: **`diffusion/SPECIALIZATION_ROADMAP.md`** (read it first in a new session). Captures the three-layer architecture the user wants and ALL pending work. Branch `claude/llm-cpp23-repo-init-1f1Il`.

**Three-layer target:** (1) specialize FRONTEND — CLI/config → generated constexpr spec + CMake build of a specialized engine+backend; (2) specialized constexpr ENGINE — model dims (vocab/seq/embed/layers/heads/d_ff) become constexpr so AOT/stack buffers replace the runtime pools (the "embedded, no heap" endpoint); (3) runtime BACKEND layers — constexpr-aware cpu/cuda dispatch. Each build tagged with **code_sha + config_sha** (the config module already emits both; config_sha folds only BuildTime fields). Build-time vs runtime split is already machine-checkable via the config `Scope` tag (model shape = BuildTime/compiled; ops knobs = Runtime). Builds on existing `sub0diff-specialize` (host axis today; this adds the model axis, informally "Ch32") + `diffusion_spec.hpp` `DiffusionStaticSpec` concept. See [[ch27-specialized-build-plan]].
