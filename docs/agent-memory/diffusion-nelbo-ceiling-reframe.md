Independent 3-expert review (2026-06-15, grounded in MDLM/LLaDA/dLLM-scaling literature) of the text-diffusion training design (full spec: `diffusion/TRAINING_DESIGN.md`). Answers the user's question "did we solve the underlying issue or just move it?": **we MOVED it.** The Ch29–Ch31 optimizer/consistency work correctly fixed the *gradient-variance* axis ([[ch31-diffusion-optimization-sandbox-plan]]: √16 +2.5pt is real but is a variance reduction that lets us train longer, NOT a floor-break). The NELBO *floor* is set elsewhere.

**The "NELBO < 2" target is a CATEGORY ERROR.** 3.5 is in NATS (=5.05 bits), t-averaged over t~U(0.02,1] so dominated by the irreducible high-t regime (loss ≈ corpus unigram entropy). The 1/t weight CANCELS the mask count in our per-token-mean form (correct MDLM Rao-Blackwellized objective). MDLM reports PPL 23-31 on LM1B = NELBO 3.1-3.4 nats on a LARGE corpus; our 3.5 on tiny Shakespeare is within ~0.3 nats — plausibly NEAR-FLOOR, not catastrophically underfit. Report NELBO as perplexity (~33 PPL) + per-t curve, not the bare scalar.

**Three floor-setting causes (any one produces an optimizer-independent NELBO ~entropy — exactly what we see; "consistency is the crux" may MASK these):**
1. MEASUREMENT: we report one conflated scalar, not a per-t loss curve. #1 missing artifact.
2. CONDITIONING (P0, top model-side suspect): noise conditioning is parameter-free additive sinusoid at 1/√D (washed by pre-norm RMSNorm) with a MIS-BANDED frequency (`time_embedding.hpp` kTimeEmbedScale=1000/base=10000 → no low-freq channel monotonic in t; aliasing). Likely near t-AGNOSTIC → collapses to marginal. Fix: learned AdaLN/FiLM time conditioning (standard MDLM/LLaDA recipe we omitted). [[conditioning-embedding-amplitude]] is related (we fixed amplitude but not the band/learnedness).
3. DATA STARVATION: tokens/param ≈ 0.1-6 vs diffusion-optimal 40-100 (Chinchilla does NOT transfer; diffusion is 2-5× more data-hungry/param but tolerates ~100-500 epochs of reuse vs AR's ~4-15 — masking = built-in augmentation). Our self-terminate/early-stop likely TRUNCATES before the reuse regime. Compute-optimal here = SMALLER properly-proportioned model (~1.5-3M, head_dim 32, d_ff 4D) + MANY more epochs, NOT a bigger model.

**Other concrete code flaws found:** P2 — exact-count + t_min=0.02 biases the 1/t estimator at low t (round(t·T) clamps to 1 while weight 1/(t·T) varies); fix raise t_min so t_min·T≥3 (≈0.05 at T=64). Exact-count also removes the Binomial mask-count spread the model faces at inference (train/inference mismatch). P3 — weight-tied head may be under-capacity for a denoiser; untie + retest. P4 (cleared) — RoPE under bidirectional attention is correct.

**Prioritized CHEAP diagnostics (do BEFORE more optimizer/consistency work):** (1) per-t CE curve — flat≈3.5 ⇒ t-agnostic/P0; monotone rising from <1 nat ⇒ near-floor. (2) single-batch overfit to <2 — can't even overfit ⇒ capacity/conditioning; overfits but held-out 3.5 ⇒ data-bound. (Earlier tiny-model overfit reached only ~5% train recall — a hint it CAN'T overfit → P0/P3; redo properly.) (3) AR baseline on identical stream — AR≈3.5 ⇒ data; AR≈2-2.5 ⇒ objective/conditioning gap. (4) measure unigram-entropy floor H0. **Highest-leverage fixes after diagnostics: learned AdaLN conditioning; many more epochs on full corpus (raise patience/min_epochs); smaller proportioned model; untie head; raise t_min.** Next chapter pivots from "make the gradient cleaner" to "is the model t-aware and is it data-bound."

**PER-T DIAGNOSTIC RESULT (2026-06-15, `--per-t` now in ch29, commit 37993c3).** Ran on the √16 checkpoint (old arch D128/L8). masked-CE rises MONOTONICALLY 1.94 nats (t=0.05) → 5.56 (t=0.95) ≈ unigram floor H0=5.67; recall 52%→3%. **CONCLUSIONS: (1) the model IS t-AWARE** — the curve is the healthy rising shape, NOT flat → the parameter-free sinusoidal conditioning WORKS; **P0 (conditioning broken / need AdaLN) is REFUTED for this model — AdaLN deprioritized.** (2) BUT low-t CE is ~1.94 nats, not the <1 a well-fit model reaches → **UNDERFIT at low t** → the binding constraint is FIT / proportions / epochs / data, NOT the optimizer and NOT conditioning. (3) The t-averaged 3.66 NELBO is dominated by the irreducible high-t tail near H0 → confirms "NELBO<2 is a category error." **Action taken:** best-candidate long run = FOUNDED arch (D256/L6, head_dim 32, d_ff 4D — fixes the old mis-proportion) + √16 consistency + RAISED patience (train into the data-reuse regime) on the full corpus. Watch the per-t low-t CE drop toward <1 as the success signal (not the conflated scalar). New reusable diagnostic: `--per-t` (+ `diffusion_loss` returns raw `mean_ce`).

**FOUNDED LONG-RUN RESULT + TREND (2026-06-16).** Best-candidate run (founded D256/L6, √16, patience40, full corpus) VALIDATED the reframe: recall 21.5%→~33% (+11pt), word-START 16.9%→~25%, best NELBO 3.52→3.34, and the **low-t train NELBO fell 1.94→~1.4 — the underfit marker closing** (founded arch fits the easy regime far better) ⇒ the ceiling was FIT/PROPORTIONS, not optimizer/conditioning. Power-law fit (`diffusion/chapters/ch29_diffusion_training/fit_trend.py`, 162 pts): NELBO=3.06+202·s^-0.55, recall=40.0−1710·s^-0.45 → asymptotes ~40% recall / ~3.06 NELBO, but diminishing HARD (recall +1.62→+0.62 pt/10k steps; 90% of remaining gain needs ~176× compute; +24h ≈ +2.5pt). **MORE STEPS is not the lever.**

**NEXT AXIS — dLLM training EFFICIENCY (how each window is consumed; researched, see TRAINING_DESIGN §11).** masked-only loss supervises ~t·T positions/forward and t~U wastes ~30% of forwards at t>0.7 (irreducible high-t loss). Top levers by gain/effort: (1) mid-t importance sampling + realized-k weighting (also fixes the P2 low-t/t_min bias), (2) complementary/antithetic masking pairs (100% token coverage/pair, ½ variance — additive to √16), (3) stratified-t across batch (tension with our shared-t — A/B). These are EFFICIENCY levers (reach the floor faster); the FLOOR is data/proportions. De-prioritized: all-position loss (breaks MD4 valid bound), RADD (conflicts — per-t shows we WANT t-conditioning), Prime (high cost). New tool: `--per-t` + `diffusion_loss.mean_ce`. Sufficiency-for-ch30 test: pending.

**MINIMAL-CASE EXPERIMENTS (2026-06-16, `--overfit N` harness + ladder/A-B; TRAINING_DESIGN §12).** Three controlled tests on the REAL training path. (1) CAPACITY LADDER (N=1/4/16/64 × D64/D128/D256, founded-proportioned): even 157K params memorize N=1/4; 1M fits N≤16 → **capacity/depth/heads are NOT the bottleneck — "do we need 8 layers/3 heads?" = NO; the founded +11pt was PROPORTIONS not size.** BUT N=64 collapsed to ~3% (marginal floor) for ALL archs incl 6M — a discrete cliff, impossible as capacity (6M holds 4096 tokens easily). (2) DECISIVE: re-ran D128 N=64 with **full-batch B=64 → FIT 99% by step 1800** (same arch that failed at 3.4% with batch=1) ⇒ **the collapse was GRADIENT VARIANCE, not capacity.** THE SESSION THROUGH-LINE: the binding constraint at this scale is **gradient QUALITY (variance/consistency)** — same mechanism as the √16 win and the t_max win — NOT capacity/optimizer/conditioning. (3) t_max 1.0 vs 0.8 A/B (matched 30k steps, seed-matched, D128): **t_max=0.8 WINS every metric** (overall 14.1→15.0%, word-START 10.4→11.0%, NELBO 4.13→4.07) — the t>0.8 tail (near entropy floor) is net-negative per compute. SHIPPED: structural **min-1-VISIBLE floor** (`k∈[1,T-1]` in `corrupt_into`, both paths; test updated) — every window keeps ≥1 visible token (context) AND ≥1 masked (target); symmetric twin of min-1-masked; removes only ~0.8% fully-blank windows so it's safe with t_max=1.0 default + Ch30 gen.
